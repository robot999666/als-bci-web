# ALS-BCI 项目知识库

本文只整理仓库现有 README、架构说明和页面文案，用于项目问答检索。若本文与可执行代码的当前状态冲突，应以根目录 README 和实际接口为准。

## 项目定位与目标

ALS-BCI 是面向 ALS 重度运动障碍人群的非侵入式脑电运动想象科研原型。系统希望把用户的运动想象脑电信号识别为左转、右转、直行和停止四类离散意图，再将识别结果表示为辅助设备可执行的控制指令。当前网站用于展示和验证从科研数据输入、信号处理、模型推理到网页结果呈现的完整技术链路。

项目不是医疗器械、诊断工具或治疗系统，不提供医疗诊断或治疗建议。当前展示的识别结果和离线准确率只用于科研实验及软件回归，不能代表对新用户的临床效果或泛化能力。

## 四分类意图

类别 0 是左手运动想象，对应“左转”；类别 1 是右手运动想象，对应“右转”；类别 2 是双脚运动想象，对应“直行”；类别 3 是舌头运动想象，对应“停止”。这四类是离散控制指令，并不是对 ALS 病情的分类。

## 算法技术路线

当前冷启动推理链路为：标准脑电窗口输入 → 数据安全校验 → 多频带分解 → 欧氏对齐（EA）→ 共空间模式（CSP）特征 → 线性判别分析（LDA）→ 四分类概率与网页结果。

输入支持 BCI Competition IV 2a 的 22 通道布局，或按固定顺序排列的 3 通道 `[C3, Cz, C4]`。采样率固定为 250 Hz，单个 trial 为 501 个时间点、约 2 秒，单位必须是微伏（μV）。

## FBCSP 的作用

FBCSP 是滤波器组共空间模式。项目先用 4–12、8–16、12–24、20–36 Hz 四个重叠频带保留运动皮层相关的 mu 和 beta 节律，再在每个频带使用 CSP 提炼具有类别判别力的空间能量特征。22 通道模型每个频带提取 6 个特征，共形成 24 维表示，最后由正则化 LDA 输出四分类概率。该方法计算量较低、可解释，适合当前小样本科研原型。

## EA 欧氏对齐的作用

不同受试者的脑电空间分布存在差异。冷启动模式用目标批次自身的协方差估计参考并做白化，使不同个体的数据分布更容易与跨受试者预训练模型对齐。当前实现会用一次请求中的全部 trial 共同计算 EA 参考，因此结果具有批次耦合性：同一个 trial 的结果可能随同批其他 trial 改变。当前接口至少需要 2 个 trial，不支持把单个实时窗口直接作为无状态请求。

## 为什么使用 C3、Cz、C4

C3 和 C4 位于左右运动皮层附近，与左右手运动想象相关；Cz 位于中央区域，可补充双脚等运动想象信息。项目提供固定顺序 `[C3, Cz, C4]` 的 3 通道版本，用较少电极支持便携演示，但信息量和精度通常低于 22 通道版本。网站也支持 BCI 2a 标准 22 通道布局。

## 在线实验平台使用说明

访问 `/lab` 可进入在线实验平台。默认的“示例数据动画”完全在浏览器端运行，用于快速理解三通道脑电波形和四分类交互，不会调用真实模型，不能当作实时采集或真实推理结果。

要运行真实模型，可选择 NPZ 文件上传。文件必须包含数值数组 `X`，形状为 `(N, 3|22, 501)`，采样率 250 Hz、单位 μV，且至少有 2 个 trial；可选标签数组 `y` 的形状为 `(N,)`，取值为 0、1、2、3。后端会检查压缩结构、容量、形状和有限值，然后返回每个 trial 的类别、置信度、四类概率；提供 `y` 时还会返回软件验证准确率。页面会显示多通道波形、当前意图、预测时间线、验证摘要和处理流程。

## 3D 数字孪生演示

`/lab#digital-twin` 中的 WebGL 三维场景通过患者、BCI 采集设备与虚拟电动轮椅的交互动画，解释“运动想象 → 脑电信号 → 模型识别 → 轮椅执行离散指令”的流程。用户可以选择左手、右手、双脚或舌头运动想象，观察虚拟轮椅执行左转、右转、直行或停止。它是帮助理解系统工作原理的交互演示，不代表已接入真实轮椅或临床设备。

## 当前已经完成的能力

当前已经完成：FastAPI REST 批量推理；3 通道和 22 通道两套 EA+FBCSP 冷启动模型的启动加载与 SHA-256 校验；NPZ 的安全读取、格式和容量校验；S3 科研样例回放；NPZ 上传与真实批量推理；多通道波形、置信度、四类概率和逐试次预测展示；CPU-only Docker 后端部署；以及 3D 交互式数字孪生流程演示。

当前没有完成或没有接入网页的能力包括：真实脑电设备通信、用户级实时 WebSocket 会话、稳定的实时 EA 参考、实时预测平滑、数据库、用户校准模型和医疗器械功能。ADS1299 采集硬件、实时数据链路、用户级对齐参考与预测平滑属于后续研究方向。

## 实验数据与结果边界

项目使用 BCI Competition IV 2a 运动想象数据。页面资料列出的跨受试者冷启动结果为约 53.6%，个体化训练九名受试者五折交叉验证平均约 71.3%，四类召回率约为 69.0%–73.6%。根目录 README 还记录了内置 S3 软件回归数据：3 通道 288 个 trial 的回归准确率为 63.54%，22 通道为 82.99%。这些数字对应不同实验设置，不能混为同一指标，也不能代表新用户的实际效果。

## 部署与安全边界

公网前端部署在 Vercel，浏览器只请求现有 FastAPI 公网入口。模型服务密钥只由后端环境变量读取，不能进入前端、浏览器请求、JavaScript bundle 或 Git。服务日志不记录完整用户问题或原始脑电内容。上传内容不会作为 pickle 或 Python 对象反序列化；模型 pickle 只从镜像内固定模型目录加载并校验摘要。
